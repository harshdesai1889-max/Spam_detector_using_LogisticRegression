# Spam_detector_using_LogisticRegression
the repo shows the basic working of machine learning to detect whether the messages are spam or not by using Logistic Regression.

## Features
- Feature extraction using vectorization
- Logistic Regression classifier
- spam predictions for new messages

## Model used: Logistic Regression
why this is used?
- More efficient classifier for text problems
- Works more good with vectorized features
- produces probability based predictions
- easy to deploy and start working

## Example of prediction
- Wow! you did a fabulous job in the project.
  prediction: Not spam.
